## About

**snaplock** is a file & folder encryption tool.

### Key Features

- AES-256 encryption
- Single bash script
- Zero dependencies
- Encrypt files & folders
- Password-protected
- Cross-platform

---

## Tech Stack

- Bash
- openssl
- AES-256

---

## Controls & Usage

| Control | Action |
|---------|--------|
| `-e` | Encrypt |
| `-d` | Decrypt |
| `-r` | Recursive |
| `-p` | Password |
| `-o` | Output path |
